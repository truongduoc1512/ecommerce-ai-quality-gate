6. Toán học toán tử OpenCV Laplacian

Lý thuyết thị giác máy tính

Toán tử Laplacian liên tục

Là đạo hàm vi phân bậc hai của hàm cường độ sáng 2 chiều $f(x, y)$:

Δf = ∇²f = ∂²f / ∂x² + ∂²f / ∂y²

Xấp xỉ sai phân trung tâm (Central Difference) trên ảnh số rời rạc:

∂²f/∂x² ≈ f(x+1, y) - 2f(x, y) + f(x-1, y)
∂²f/∂y² ≈ f(x, y+1) - 2f(x, y) + f(x, y-1)

Ma trận tích chập (Convolution Kernel)

Biểu thức sai phân rời rạc tương đương với ma trận Kernel $3 \times 3$ chuẩn:

K = [ 0, 1, 0 ]
    [ 1, -4, 1 ]
    [ 0, 1, 0 ]

Toán tử phản hồi cực đại tại các biên cạnh đột biến và triệt tiêu tại vùng ảnh phẳng.

7. Bản chất phương sai (Variance) & Quy trình 5 bước

Thuật toán Pech-Pacheco

Bản chất của Variance (σ²)

μ = (1 / MN) ∑ L(x, y)
σ² = (1 / MN) ∑ (L(x, y) - μ)²
  • Ảnh nét: Tương phản cạnh viền cao → giá trị $L(x,y)$ biến thiên mạnh → σ² rất cao.
  • Ảnh mờ: Bị làm mịn biên độ → giá trị $L(x,y)$ tiệm cận 0 → σ² rất thấp.

Quy trình xử lý 5 bước chuẩn hóa

  1. Đọc ảnh BGR vào bộ nhớ đệm (RAM).
  2. Chuyển đổi sang ảnh xám cv2.COLOR_BGR2GRAY.
  3. Resize kích thước cạnh lớn nhất về 500px.
  4. Áp dụng cv2.Laplacian(gray, cv2.CV_64F).
  5. Tính toán phương sai bằng hàm .var().

8. Kiến trúc mạng YOLOv8: Backbone & Neck

Deep Learning Architecture

Backbone: Modified CSPDarknet

  • Khối C2f: Thay thế C3 từ YOLOv5; chia nhánh gradient và bổ sung shortcut kết nối giúp học đặc trưng phong phú với ít tham số hơn.
  • Khối SPPF: Tổng hợp ngữ cảnh đa trường nhìn (Multi Receptive Field) ở cuối Backbone.

Neck: PAN-FPN Đa tỷ lệ

  • Hợp nhất đặc trưng hai chiều (Top-down & Bottom-up).
  • Cung cấp 3 mức bản đồ đặc trưng:
    • P3/8: Độ phân giải cao → Dò vật thể nhỏ.
    • P4/16: Tầm trung → Dò vật thể vừa.
    • P5/32: Ngữ cảnh rộng → Dò vật thể lớn.

9. YOLOv8: Decoupled Head & Hàm mất mát

Học máy nâng cao

Anchor-Free & Task-Aligned Assigner

  • Decoupled Head: Tách riêng nhánh phân loại nhãn và nhánh dự đoán vị trí hộp.
  • Anchor-Free: Dự đoán trực tiếp khoảng cách từ tâm cell đến 4 cạnh hộp $(l, t, r, b)$.
  • Gán nhãn mẫu (TAL): Dựa trên công thức $t = s^\alpha \times \text{IoU}^\beta$ để tối ưu căn chỉnh.

Tổ hợp 3 hàm mất mát (Total Loss)

L_total = λ_cls L_cls + λ_box L_box + λ_dfl L_dfl
  • BCE Loss ($L_{cls}$): Phân loại nhãn chính xác.
  • CIoU Loss ($L_{box}$): Tối ưu tâm hộp, tỷ lệ khung hình và diện tích giao thoa.
  • DFL ($L_{dfl}$): Tinh chỉnh tọa độ bounding box tiệm cận mức pixel.

10. Trích xuất Bounding Box & Tỷ lệ bao phủ

Tiêu chí E-commerce

Hậu xử lý Non-Maximum Suppression (NMS)

  • Mô hình sinh ra ma trận Tensor $N \times 6$: $[x_1, y_1, x_2, y_2, \text{conf}, \text{cls}]$.
  • Lọc bỏ các box có $\text{conf} < 0.25$.
  • Triệt tiêu các box chồng lấn có chỉ số $\text{IoU} > 0.45$:
    IoU(A, B) = Area(A ∩ B) / Area(A ∪ B)

Công thức tính Coverage Ratio

Area_box = (x_max - x_min) * (y_max - y_min)
Ratio_object = Area_box / (W * H)
max_object_ratio = max(Ratio_object)

Ngưỡng chuẩn hóa: $0.08 \le \text{max\_object\_ratio} \le 0.85$. Nếu dưới 0.08, ảnh bị đánh giá là chụp quá xa hoặc sản phẩm quá nhỏ.

14. Phân tích trường hợp lỗi (Failure Analysis)

Root Cause Analysis

Phân tích 7 trường hợp nhận định sai

  • 4 Ca False Negatives:
    • Mẫu #12, #27: Rung lắc nhẹ làm phương sai σ² < 65, mất biên cạnh.
    • Mẫu #39: Bị che khuất > 60%, điểm tin cậy chỉ đạt 0.41 (dưới ngưỡng 0.5).
    • Mẫu #44: Kích thước bounding box thực tế quá nhỏ (< 16x16px).
  • 3 Ca False Positives:
    • Mẫu #08, #19: Mặt sàn phản quang gây kích hoạt sai cụm tích chập.
    • Mẫu #33: Trùng box do IoU = 0.48 lọt qua ngưỡng lọc NMS 0.45.

Giải pháp tối ưu hóa tiếp theo

  • Bộ lọc tiền xử lý: Tinh chỉnh ngưỡng phương sai động thích ứng theo độ sáng trung bình.
  • Data Augmentation: Bổ sung tập dữ liệu huấn luyện Mosaic/MixUp mô phỏng che khuất.
  • Soft-NMS: Thử nghiệm Soft-NMS nhằm giảm thiểu hiện tượng trùng lặp bounding box.
